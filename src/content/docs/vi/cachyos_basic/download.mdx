## Nguồn ISO chính thức

ISO của CachyOS có thể được lấy từ các nguồn sau:

*   [Website](<https://cachyos.org/download>)
*   [SourceForge](<https://sourceforge.net/projects/cachyos-arch/files/>)
*   [CachyOS Mirror](<https://mirror.cachyos.org/ISO/>)

## Xác thực tính toàn vẹn của ISO với SHA256

:::caution[CẢNH BÁO]
Luôn thực hiện thêm một bước để xác minh tính toàn vẹn của ISO nhằm tránh bất kỳ sự cố không mong muốn nào trong quá trình cài đặt hoặc khi tạo phương tiện khởi động (bootable media).
:::

**Phiên bản ISO hiện tại:** `251129`

**SHA256 Hash:** `2ab25f72ce8fece890b440cf9e260fc3d57ae4f5fb5308086f670240de02da7b`

<Tabs>

<TabItem label='Windows'>

<Steps>

1. Tải xuống [tệp](https://mirror.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sha256) chứa **SHA256 Hash** **(Mở tệp này bằng Trình chỉnh sửa văn bản, ví dụ: Notepad).**
2. Mở CMD hoặc PowerShell với quyền Quản trị viên và [điều hướng](<https://www.wikihow.com/Change-Directories-in-Command-Prompt>) đến đường dẫn nơi lưu trữ tệp ISO và tệp SHA256.
3. Thực thi lệnh sau:
   ```powershell
   # Ví dụ:
   certUtil -hashfile cachyos-desktop-linux-251129.iso SHA256
   ```
4. So sánh kết quả **hash** của certUtil với **hash** từ tệp đã tải xuống ở **Bước 1**. Nếu chúng khớp nhau, bạn có thể tiếp tục cài đặt CachyOS.

</Steps>

</TabItem>

<TabItem label='Linux'>

<Steps>

1. Tải xuống [tệp](https://mirror.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sha256) chứa **SHA256 Hash**.
2. Mở một terminal, điều hướng đến thư mục chứa tệp `.sha256`, và thực thi các lệnh sau:
   ```sh
   # Ví dụ:
   cd Downloads/
   cat cachyos-desktop-linux-251129.iso.sha256
   # 2ab25f72ce8fece890b440cf9e260fc3d57ae4f5fb5308086f670240de02da7b
   ```
3. So sánh kết quả từ **Bước 2** và thực thi lệnh sau để kiểm tra **hash** của tệp ISO:
   ```sh
   # Ví dụ:
   sha256sum cachyos-desktop-linux-251129.iso
   ```
4. Nếu các **hash** từ **Bước 2** và **Bước 3** khớp nhau, bạn có thể tiếp tục cài đặt CachyOS.

</Steps>

</TabItem>

<TabItem label='macOS'>

<Steps>

1. Tải xuống [tệp](https://mirror.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sha256) chứa **SHA256 Hash**.
2. Mở một terminal, điều hướng đến thư mục chứa tệp `.sha256`, và thực thi các lệnh sau:
   ```sh
   # Ví dụ:
   cd Downloads/
   cat cachyos-desktop-linux-251129.iso.sha256
   # 2ab25f72ce8fece890b440cf9e260fc3d57ae4f5fb5308086f670240de02da7b
   ```
3. So sánh kết quả từ **Bước 2** và thực thi lệnh sau để kiểm tra **hash** của tệp ISO:
   ```sh

   shasum -a 256 cachyos-desktop-linux-251129.iso
   ```
4. Nếu các **hash** từ **Bước 2** và **Bước 3** khớp nhau, bạn có thể tiếp tục cài đặt CachyOS.

</Steps>

## Xác minh tính xác thực của ảnh ISO (Linux)

Để xác minh tính xác thực của tệp ISO và đảm bảo rằng đó là tệp chính thức được phát hành bởi nhóm phát triển CachyOS:

<Steps>

1. Nhập khóa GPG để xác minh tính xác thực:

   ```shell
   gpg --keyserver hkps://keys.openpgp.org --recv-key F3B607488DB35A47
   ```

2. Tải xuống tệp ISO và tệp chữ ký [.sig](https://cdn77.cachyos.org/ISO/desktop/251129/cachyos-desktop-linux-251129.iso.sig) của nó, sau đó chạy lệnh sau (bằng cách thay thế `full_iso_name.iso` bằng tên tệp ISO thực tế):
   ```shell
   gpg --verify full_iso_name.iso.sig full_iso_name.iso
   ```

   Nếu bạn nhận được kết quả **Good signature** (Chữ ký hợp lệ), tệp ISO là chính hãng:
   ```
   gpg: Signature made sáb 29 nov 2025 13:10:22 -03
   gpg:                using RSA key 882DCFE48E2051D48E2562ABF3B607488DB35A47
   gpg: Good signature from "CachyOS <admin@cachyos.org>" [unknown]
   gpg: WARNING: This key is not certified with a trusted signature!
   gpg:          There is no indication that the signature belongs to the owner.
   Primary key fingerprint: 882D CFE4 8E20 51D4 8E25  62AB F3B6 0748 8DB3 5A47
   ```

</Steps>

:::danger
Nếu kết quả không trả về chuỗi **Good signature** (Chữ ký hợp lệ) hoặc ID khóa không khớp, **đừng sử dụng** ảnh ISO đó. Hãy đảm bảo rằng ảnh đã tải xuống đến từ một nguồn CachyOS hợp pháp, vì một chữ ký không hợp lệ có thể cho thấy ISO đã bị giả mạo.
:::

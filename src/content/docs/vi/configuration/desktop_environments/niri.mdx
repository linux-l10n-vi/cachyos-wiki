## Phím tắt

Hầu hết các tổ hợp phím đều yêu cầu sử dụng phím mod, trong trường hợp của chúng tôi là phím Windows (được gọi là SUPER), bạn có thể thay đổi nó trong tệp cấu hình.

### Điều khiển ứng dụng

| Mô tả | Phím |
|-------------|-----|
| Mở terminal | <Kbd linux="Super+Return" /> |
| Mở Wofi (Trình khởi chạy chương trình) | <Kbd linux="Super+Space" /> |
| Mở trình duyệt (Firefox) | <Kbd linux="Super+B" /> |
| Mở trình quản lý tệp | <Kbd linux="Super+E" /> |
| Đóng cửa sổ đang tập trung | <Kbd linux="Super+Q" /> |
| Khóa màn hình | <Kbd linux="Super+Alt+L" /> |

### Điều hướng không gian làm việc

| Mô tả | Phím |
|-------------|-----|
| Chuyển đến không gian làm việc (1-9) | <Kbd linux="Super+1" /> đến <Kbd linux="Super+9" /> |
| Không gian làm việc trước đó | <Kbd linux="Super+Tab" /> |
| Di chuyển giữa các không gian làm việc với cuộn chuột | <Kbd linux="Super+Scroll" /> |

### Điều hướng cửa sổ

| Mô tả | Phím |
|-------------|-----|
| Tập trung cửa sổ/cột phía trên | <Kbd linux="Super+ArrowUp" /> hoặc <Kbd linux="Super+K" /> |
| Tập trung cửa sổ/cột phía dưới | <Kbd linux="Super+ArrowDown" /> hoặc <Kbd linux="Super+J" /> |
| Tập trung cột bên trái | <Kbd linux="Super+ArrowLeft" /> hoặc <Kbd linux="Super+H" /> |
| Tập trung cột bên phải | <Kbd linux="Super+ArrowRight" /> hoặc <Kbd linux="Super+L" /> |
| Tập trung cột đầu tiên | <Kbd linux="Super+Home" /> |
| Tập trung cột cuối cùng | <Kbd linux="Super+End" /> |

### Điều hướng màn hình

| Mô tả | Phím |
|-------------|-----|
| Tập trung màn hình bên trái | <Kbd linux="Super+Shift+ArrowLeft" /> |

| Tập trung màn hình phía trên | <Kbd linux="Super+Shift+ArrowUp" /> |

## FAQ

### Điều gì làm Niri khác biệt so với các trình quản lý cửa sổ khác?

Niri sử dụng cách tiếp cận xếp lát-cuộn độc đáo trong đó các cửa sổ được sắp xếp trong các cột có thể cuộn theo chiều ngang. Điều này cung cấp một desktop vô hạn đặc biệt hữu ích cho màn hình siêu rộng và quy trình làm việc yêu cầu nhiều ứng dụng mở.

### Làm thế nào để thay đổi bố cục bàn phím?

Chỉnh sửa phần input trong tệp cấu hình của bạn:

```txt title='Ví dụ'
input {
    keyboard {
        xkb {
            layout "us" // Thay từ "de" thành bố cục bạn muốn
        }
    }
}
```

### Tôi có thể tùy chỉnh khoảng cách và giao diện cửa sổ không?

Có, bạn có thể sửa đổi phần layout:

```txt title='Ví dụ'
layout {
    gaps 8 // Thay đổi kích thước khoảng cách

    tập trung-ring {
        width 2
        active-color "#màu-của-bạn"
        inactive-color "#màu-của-bạn"
    }
}
```

### Làm thế nào để thêm nhiều ứng dụng khởi động hơn?

Thêm chúng vào phần startup:

```txt title='Ví dụ'
spawn-at-startup "ứng-dụng-của-bạn"
```

### Phím thoát khẩn cấp dùng để làm gì?

Phím tắt `Super+Escape` được thiết kế để khôi phục điều khiển khi một ứng dụng toàn màn hình chặn các phím tắt của bạn. Nó vô hiệu hóa bất kỳ trình ức chế phím tắt bàn phím đang hoạt động nào.

### Làm thế nào để cấu hình nhiều màn hình?

Bỏ ghi chú và sửa đổi phần output cho các màn hình cụ thể của bạn. Chạy `niri msg outputs` để lấy tên đúng:

```txt title='Ví dụ'
output "DP-1" {
    mode "1920x1080@60.000"
    scale 1
}
```
